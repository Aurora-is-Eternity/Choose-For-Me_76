## 逐条说明

### 要求 1：项目命名与开源平台

- 仓库名：`Choose-For-Me_76`，命名规则 `项目名称_学号后两位`（2025131076 → `76`）
- 项目是一个真实可用的工具：零依赖、纯静态、26 个单元测试、可离线打开
- 不是占位仓库：核心逻辑有测试保护，UI 有键盘与无障碍处理，CI 在 Node 22 / 24 双版本跑通

### 要求 5：华为「五看三定」分析

[`docs/五看三定.md`](五看三定.md)，九个部分：

1. 结论先行（一页表格）
2. 看行业/趋势：选择过载、轻量工具回潮、无广告与隐私、开源替代小程序的四条趋势
3. 看市场/客户：四层客户画像、客户付出的是时间与社交货币、三个一手证据、市场量级（标注为假设）
4. 看竞争：转盘类产品的矩阵对比、三个格局判断、差异化与「代码壁垒约等于 0」的诚实评估
5. 看自己：能力盘点（实测数据）、SWOT、三条自我批评
6. 看机会：四个机会点按吸引力×可行性排序，包括一份「不做清单」
7. 定战略控制点：控制点不是代码，而是选项库 + 无广告信任 + 零依赖可自托管
8. 定目标：北极星指标（被复用的选项组数）、四个时间盒、三项反指标
9. 定策略：五条策略、路线图、风险对策表、每月只看三个数
